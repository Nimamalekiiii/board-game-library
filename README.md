# Board Game Library 

A Java-based board game library application developed as a software development project.

##  About

This project is a Java application for managing a collection of board games and related data.

The project uses a structured Java codebase together with a database and SQL scripts for storing and working with application data.

##  Tech Stack

- Java
- SQL
- JDBC
- Database
